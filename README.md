# 白马王朗 · 周末自驾手册

一份为 2026 年 11 月 21–22 日成都出发设计的 2 天 1 夜交互式自驾攻略。

## 页面功能

- 两日行程时间轴与游玩偏好切换
- 周末天气与初冬驾驶提醒
- 成都至白马王朗路线示意及高德导航
- 可修改人数、油耗、票价和住宿的预算计算器
- 保存在浏览器本地的装备清单
- 信息来源、票务电话与临行复核入口

## 本地预览

直接打开 `dist/index.html`，或使用任意静态文件服务器托管 `dist/`。

## 部署

GitHub Pages 从 `main` 分支的 `docs/` 目录发布。`dist/` 保留为原始静态构建产物。

> 攻略信息核验于 2026-11-13。天气、路况、票价、观光车线路和景区开放状态以出发前官方公告为准。
